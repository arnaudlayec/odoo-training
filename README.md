
# Description
Odoo Developper Essential course.
Ordered by Ambient IT.
Inspired from well-known books in the Odoo community.
Follows a real-life development use-case of a vertical modules for Library management.
Adapted for a live 3-days in-person session.
30% theory / 70% practise.
Main exercices sream plus advanced/bonus exercices per chapter.
